合同审查台 Windows 试用版

使用提示
个人实验性工具，用于辅助审查与流程研究，私用清单覆盖有限，可能存在误报漏报，实际签署前需要结合交易事实专业复核。
模型审查意见与建议修改由所选AI模型生成，请逐项对照合同原文和交易事实核对。新审查使用你配置的模型API。

开始使用
1. 先完整解压 ZIP，不要在压缩包里直接运行。
2. 双击“合同审查台.exe”，打开独立的审查台窗口。
3. 关闭这个窗口就退出软件；审查等任务仍在运行时，先等任务结束。
   再次双击会打开已有窗口，不另外启动第二份。

首次启动
本公开源码构建的工作台首次启动为空，不附带合同模板、真实合同或已有审查记录。
上传自己的 DOCX，填写我方主体与审查要求，并在设置里配置模型后开始审查。
代码中的合成测试夹具仅供开发验证，不是程序自带的审查示例。

审核自己的合同
在工作台“设置”里填写你自己的模型服务地址、API Key 和模型名称。
新审查、讨论与复审需要联网，使用所选模型服务的额度；合同内容会发送到该服务。
本试用版没有内置付费密钥，也不需要安装本机 Codex。

数据与文件
程序会在旁边创建“我的数据”文件夹，保存合同、审查记录和设置。请解压到可写文件夹。
请勿删除或改动“_internal”目录；发给别人试用时请发送原始 ZIP，不要转发自己用过的整个文件夹。
API Key 由当前 Windows 账户加密保存，换电脑或换 Windows 账户后通常需要重新填写。
下载 Word 文件后，可用 Word 或其他兼容软件查看。生成文件不要求预先安装 Microsoft Word。

退出与更新
结束使用时，关闭审查台窗口。
拿到新版后先退出旧版，再将新版解压到另一个目录。需要保留记录时，把旧版“我的数据”移入尚未运行过的新目录；先核对目标不存在，别覆盖另一份记录。
本期没有自动更新和安装向导。

移除软件
工作台左下“设置”里有“移除软件”。默认保留“我的数据”，确认窗口会显示具体位置。
如需同时移除记录、讨论和模型设置，勾选对应选项；数据送到 Windows 回收站。
确认后程序退出，再完成清理并显示结果。自己放进程序目录的其他文件不会跟着清除。
另外下载到其他位置的 Word 文件不受影响；原始 ZIP 也需自行删除。

第一次使用，可以检查这三步
1. 双击打开，确认工作台列表为空，在设置里填写自己的模型连接。
2. 上传自己的 DOCX，确认审查清单和审查要求，按页面流程完成准备与审查。
3. 关闭审查台，再双击打开，检查刚才的记录是否还在；需要时核对改稿并导出 Word。
准备、审查、讨论和复审会使用所选服务商的模型额度；读取和导出已有结果不会调用模型。

适用环境
Windows 10/11 64位，使用 Microsoft Edge WebView2 Runtime 显示界面。多数电脑已有；缺少时启动会提示安装微软运行组件，不要求安装 Python、Codex 或 Word。
此包为求职作品的试用原型，审查意见与修改文字仍需由使用者核对后采用。
首次分发未购买代码签名证书，系统可能显示未知发布者提示；只运行你确认来源的文件。
